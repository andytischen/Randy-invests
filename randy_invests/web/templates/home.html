How the desk works

Three steps. Suitability still comes before any real commitment.

01

Compare in one view

Cards and a side-by-side table so a retail investor can see minimums, fees, holds, and access without a pitch deck.

02

Check an illustrative fit

Enter a dollar amount on the tiers page. We highlight the highest program whose minimum you meet. It is not a recommendation.

Express interest

Send a name, email, and intended amount. Payments are mocked. A live firm would follow with KYC and a written agreement.

Built next to the research engine

Randy Invests already ships a CLI that fetches market data, scores technical patterns, and trains an ML ensemble. This portal is the retail front door — access tiers, not a replacement for the model output.

Signed-in personalization (later)

There is no account system in this release. When auth lands, a retail user should see the tier they already hold, a path to upgrade, and statements against the same catalogue. Until then the public /tiers page plus an optional amount highlighter is the whole experience.
